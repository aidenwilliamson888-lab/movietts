🎙️ Movie Podcast Generator

TMDB Metadata → Random Titles → TTS Audio → Podcast Package → R2 / RSS Ready

🎬
Movie Input
Masukkan TMDB Movie ID yang ingin dibuat menjadi episode podcast. Maksimal 100 ID per batch.
Bisa menggunakan baris baru, koma, atau spasi. Duplicate ID otomatis dihapus.
🌎
TMDB Settings
Metadata movie akan diambil menggunakan bahasa yang dipilih.
Title, overview, genre dan metadata mengikuti data terjemahan yang tersedia pada TMDB.
🏷️
Random Title Templates
Masukkan beberapa template. Setiap movie akan memilih tepat satu template secara random.
🎲 Cara kerja random: Jika terdapat 5 template dan lo generate 100 movie, maka setiap movie memilih 1 template dari 5 pilihan tersebut.

Jadi: 100 movie = 100 final title.

Variables: {TITLE}, {YEAR}, {ID}
📝
Episode Description
Description ini nantinya akan menjadi description episode RSS.
Variables: {TITLE} {YEAR} {ID} {GENRE} {DIRECTOR} {RATING} {OVERVIEW} {CTA1} {CTA2} {CTA_URL}
🔗
CTA Settings
CTA URL otomatis menggunakan Base URL + TMDB ID.
Contoh: https://example.pages.dev/550
🎙️
Audio / ElevenLabs
Audio episode akan disimpan sebagai MP3 dan diberi nama yang aman untuk penggunaan R2/RSS.
Voice ID bisa diganti kapan saja. API key tetap berada di Cloudflare Secret.
Untuk podcast kita gunakan 44.1 kHz sebagai default. Apple mencantumkan MP3 44.1 kHz sebagai format yang diterima untuk RSS feeds. :contentReference[oaicite:1]{index=1}
Variables: {TITLE} {YEAR}
📦
Podcast Output
Package dibuat khusus agar metadata dan audio siap digunakan pada tahap Cloudflare R2 → RSS.
