🎬 Movie TTS Generator

TMDB Metadata → Random Title → Description → ElevenLabs TTS → MP3 ZIP

🎬 Movie Input
Masukkan TMDB Movie ID. Maksimal 100 ID per batch.
Bisa dipisahkan dengan baris baru, koma, atau spasi.
🌎 TMDB Settings
Pilih bahasa metadata yang ingin digunakan.
Title, overview, genre dan metadata akan mengikuti terjemahan yang tersedia di TMDB.
🏷️ Title Templates
Masukkan beberapa template. Setiap film hanya akan memilih 1 template secara random.
Random system:
Jika ada 5 template dan generate 100 film, setiap film akan memilih 1 dari 5 template secara random. Jadi hasil akhirnya tetap 100 film = 100 title.

Variables: {TITLE}, {YEAR}, {ID}
📝 Description
Template description untuk setiap movie.
Variables: {TITLE} {YEAR} {ID} {GENRE} {DIRECTOR} {RATING} {OVERVIEW} {CTA1} {CTA2} {CTA_URL}
